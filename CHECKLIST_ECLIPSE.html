  2. Seleccionar: Apache → Tomcat v9.0
  3. Especificar ruta de instalación de Tomcat
  4. Arrastrar proyecto al servidor

⏳ PASO 4: INICIAR SERVIDOR

Acciones:

  1. En vista Servers, click derecho en Tomcat
  2. Seleccionar: Start
  3. Esperar mensaje: Server started

⚠️ SOLUCIÓN DE PROBLEMAS COMUNES

Error: "Port 8080 already in use"

  • Cerrar otros programas usando puerto 8080
  • En Tomcat: cambiar puerto en server.xml

Error: "The project cannot be built"

  • Click derecho en proyecto → Build Path → Configure Build Path
  • Verificar que mysql-connector.jar esté en Libraries

Error: "404 - Not Found"

  • Verificar que proyecto esté desplegado en Tomcat
  • Context path debe ser: /HypnoElectronicAuth
